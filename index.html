macOS
  1. Открой скачанный zip — появится приложение Overdrive. Перетащи его в «Программы».
  2. Первый запуск: правый клик по приложению → Открыть → Открыть.
  3. Если пишет «повреждено» или «не удаётся открыть» — открой Терминал, вставь строку ниже и нажми Enter:
  1. Open the downloaded zip and you'll get the Overdrive app. Drag it into Applications.
  2. First launch: right-click the app → Open → Open.
  3. If it says "damaged" or "can't be opened", open Terminal, paste the line below and press Enter:
APP="$(ls -d /Applications/[Oo]verdrive*.app ~/Downloads/[Oo]verdrive*.app 2>/dev/null | head -1)"; chmod +x "$APP"/Contents/MacOS/*; xattr -cr "$APP"; codesign --force --deep -s - "$APP"; open "$APP"
Windows
  1. Правый клик по zip → Извлечь всё.
  2. Открой папку и запусти Overdrive.exe.
  3. Если синее окно «Windows защитила компьютер» — нажми Подробнее → Выполнить в любом случае.
  1. Right-click the zip → Extract All.
  2. Open the folder and run Overdrive.exe.
  3. If a blue "Windows protected your PC" window appears, click More info → Run anyway.

  3. Нажми Установить. Новые версии ставятся поверх, прогресс сохраняется.
  1. Download the APK and open it from the notification or the Downloads folder.
  2. The phone will ask to allow installing apps from this source. Allow it.
  3. Tap Install. New versions install over the old one and keep your progress.
